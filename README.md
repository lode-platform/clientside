# clientside
Consolidated html/css/js frame work for client side (browser) functionality.

This project is in very early stages and does not represent an initial release.

Additional information and contribution guidelines will be added as the project progresses.  In the mean time bug reports are welcome but communication may be infrequent or limited for the moment.
